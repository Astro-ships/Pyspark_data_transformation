# PySpark Data Transformation

This repository contains my hands-on work with **PySpark and Apache Spark**, using synthetic banking data for data transformation and cleaning.

The data contains common data-quality issues such as null values, duplicate records, inconsistent values, and unstandardized fields.

The current work focuses on exploring the data and applying transformations using PySpark DataFrames, including filtering, handling nulls, detecting duplicates, standardizing values, joins, and aggregations.

As the project progresses, more PySpark concepts and transformations will be added, including advanced DataFrame operations, window functions, and Spark performance concepts.

## Current Work

* Reading NDJSON data with PySpark
* Exploring DataFrame schemas and values
* Handling null values
* Detecting duplicate records
* Standardizing inconsistent values
* Using lookup tables for transformations
* Joining DataFrames
* Using `coalesce()`
* Filtering and selecting data
* Grouping and aggregating data
* Understanding Spark transformations and actions
* Working with Spark's lazy evaluation
